# Synthetic Test Documents for List of Dates Generator

This folder contains artificially generated legal documents for testing the date extraction, translation, OCR, and authority check functionalities.

- **Files**

- `civil_suit_sample.docx` - Civil suit plaint with multiple dates
- `criminal_case_sample.pdf` - Criminal case FIR and charge sheet
- `property_dispute_sample.docx` - Property dispute with timeline
- `contract_breach_sample.pdf` - Contract breach case details
- `hindi_full_legal_doc.docx` - Verbose Hindi civil suit plaint with detailed factual chronology
- `synthetic_judgment.docx` - Synthetic Indian High Court judgment (DOCX) for summarizer testing
- `synthetic_judgment.pdf` - Same judgment in PDF format
- `opposing_party_claim.docx` - Synthetic opposing party claim (written defence & counter‑claim) in Hindi
- `opposing_party_claim.pdf` - PDF version of the opposing party claim

## Purpose

These documents are for testing the `List of Dates` generator tool that extracts chronological events from legal documents.

## Date Format Expected

The system extracts dates in various Indian legal formats:
- DD/MM/YYYY
- DD-MM-YYYY
- DD.MM.YYYY
- Month DD, YYYY
- DD Month YYYY
