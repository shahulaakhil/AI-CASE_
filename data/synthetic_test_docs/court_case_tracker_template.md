**How to Use**
1. Duplicate this file for each case you are tracking.
2. Fill in the **Case Overview** section first.
3. Update the **Timeline of Events** after every filing, hearing, or order.
4. Keep the **Upcoming Deadlines** table current to avoid missed dates.
5. Attach or link all relevant documents in the **Key Documents** table.
6. Review the **Notes** section after each court appearance.

This markdown can be rendered directly in VS Code, GitHub, or any markdown viewer, and can be exported to PDF/Word if needed.
